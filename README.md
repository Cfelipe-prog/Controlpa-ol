# Control de herramientas - Pañol

Proyecto React + Vite listo para producción.

## Cómo usar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Logo

Si quieres mostrar el logo en el PDF, coloca tu archivo como:

`public/logo-arauco.png`

Si no existe, el PDF se genera igual sin logo.
